## 🆘 Se Errar Durante a Gravação

**"Não encontrei o gráfico a tempo?"**
```
→ Continue falando naturalmente
→ Pause a gravação
→ Encontre o gráfico (Ctrl+F no notebook)
→ Recomece daquele ponto
→ Edita depois (corta/junta as partes)
```

**"Cliquei no gráfico errado?"**
```
→ Continua como se nada tivesse acontecido
→ Descreve o que está na tela
→ Audiência não saberá que "errou"
```

**"Notebook travou?"**
```
→ Pause a gravação
→ Execute a célula novamente (Run)
→ Continua da onde parou
```
